AI、ML、DL 的包含关系	AI ⊃ ML ⊃ DL。ML 从数据学规律；DL 是用多层神经网络的 ML。	AIIO::D1 AIIO::ai-basics
Artificial Intelligence（AI）	让机器表现出智能行为的总称，包括规则系统、搜索、机器学习等。	AIIO::D1 AIIO::ai-basics
Machine Learning（ML）	从数据中学习模式来做预测或决策，而不是人工写死规则。	AIIO::D1 AIIO::ai-basics
Deep Learning（DL）	用多层（深层）神经网络自动学习特征表示；数据和算力越多效果越好，是 GPU 需求的主要来源。	AIIO::D1 AIIO::ai-basics
Supervised learning（监督学习）	训练数据带标签（输入→正确答案）。典型任务：分类、回归。	AIIO::D1 AIIO::ai-basics
Unsupervised learning（无监督学习）	数据没有标签，模型自己发现结构。典型：聚类、降维、异常检测。	AIIO::D1 AIIO::ai-basics
Reinforcement learning（强化学习）	智能体在环境中行动，根据奖励信号学习策略。用于机器人、游戏、RLHF。	AIIO::D1 AIIO::ai-basics
Self-supervised learning（自监督学习）	从数据本身构造监督信号（例如预测下一个 token、遮盖词），LLM 预训练就是这种方式。	AIIO::D1 AIIO::ai-basics
Classification vs Regression	分类：输出离散类别（猫/狗）；回归：输出连续数值（房价）。	AIIO::D1 AIIO::ai-basics
Clustering（聚类）	把相似样本自动分组，无需标签。例：客户分群。	AIIO::D1 AIIO::ai-basics
Neural network（神经网络）	由层层神经元（加权求和 + 激活函数）组成的模型，参数是权重和偏置。	AIIO::D1 AIIO::ai-basics
Weights and biases（权重与偏置）	神经网络中训练得到的参数。“参数量 70B”指的就是这些数值的个数。	AIIO::D1 AIIO::ai-basics
Activation function（激活函数）	给网络引入非线性，例如 ReLU、GELU、Sigmoid。没有它，多层网络等价于一层线性变换。	AIIO::D1 AIIO::ai-basics
Loss function（损失函数）	衡量模型预测和真实值差距的函数，训练目标是最小化它。例：交叉熵、均方误差。	AIIO::D1 AIIO::ai-basics
Gradient descent（梯度下降）	沿损失函数梯度的反方向更新参数，逐步降低损失。	AIIO::D1 AIIO::ai-basics
Backpropagation（反向传播）	用链式法则从输出层往回计算每个参数的梯度，是训练的核心步骤，推理时不需要。	AIIO::D1 AIIO::ai-basics
Optimizer（优化器）	决定如何用梯度更新参数的算法，例如 SGD、Adam、AdamW。Adam 需要额外保存两份状态（动量和方差）。	AIIO::D1 AIIO::ai-basics
Learning rate（学习率）	每次参数更新的步长。太大不收敛，太小训练慢。	AIIO::D1 AIIO::ai-basics
Hyperparameter（超参数）	训练前人为设定、不由训练学习的配置：学习率、batch size、层数、epoch 数等。	AIIO::D1 AIIO::ai-basics
Epoch	完整遍历一次训练数据集。	AIIO::D1 AIIO::ai-basics
Batch / mini-batch	一次前向+反向处理的一组样本。batch size 影响显存占用、吞吐和收敛。	AIIO::D1 AIIO::ai-basics
Iteration / step	处理一个 mini-batch 并更新一次参数。1 个 epoch = 数据量 ÷ batch size 个 step。	AIIO::D1 AIIO::ai-basics
Overfitting（过拟合）	模型在训练集上很好、在新数据上差，记住了噪声。对策：更多数据、正则化、dropout、early stopping。	AIIO::D1 AIIO::ai-basics
Underfitting（欠拟合）	模型太简单或训练不够，训练集上都表现差。	AIIO::D1 AIIO::ai-basics
Training / validation / test set	训练集用于学参数；验证集调超参、早停；测试集最终评估，训练中不可见。	AIIO::D1 AIIO::ai-basics
CNN（卷积神经网络）	用卷积核提取局部特征，擅长图像和视频。	AIIO::D1 AIIO::ai-basics
RNN / LSTM	按时间步处理序列的网络，早期用于语音和文本；长序列难并行，已大量被 Transformer 取代。	AIIO::D1 AIIO::ai-basics
Transformer	基于自注意力（self-attention）的架构，可并行处理整个序列。现代 LLM、ViT 都基于它。	AIIO::D1 AIIO::ai-basics
Self-attention（自注意力）	序列中每个 token 计算与其他所有 token 的相关性并加权汇总；计算量随序列长度平方增长。	AIIO::D1 AIIO::ai-basics
Foundation model（基础模型）	在海量数据上预训练、可适配多种下游任务的大模型，例如 LLM、视觉大模型。	AIIO::D1 AIIO::ai-basics
Generative AI（生成式 AI）	生成新内容（文本、图像、代码、音频、视频）的模型，如 LLM、扩散模型。	AIIO::D1 AIIO::ai-basics
Diffusion model（扩散模型）	通过逐步去噪从随机噪声生成图像/视频的生成模型。	AIIO::D1 AIIO::ai-basics
Agentic AI（智能体 AI）	LLM 结合规划、工具调用、记忆，能自主多步完成任务。	AIIO::D1 AIIO::ai-basics
Computer vision（计算机视觉）	让机器理解图像和视频：分类、检测、分割、跟踪。	AIIO::D1 AIIO::ai-basics
NLP（自然语言处理）	处理人类语言：翻译、摘要、问答、情感分析。	AIIO::D1 AIIO::ai-basics
Recommender system（推荐系统）	根据用户行为推荐内容；大型 embedding 表，数据量大。NVIDIA 对应 Merlin。	AIIO::D1 AIIO::ai-basics
AI 端到端工作流顺序	数据准备（采集/清洗/标注/ETL）→ 训练 → 优化（量化/剪枝/TensorRT）→ 部署推理 → 监控与再训练。	AIIO::D1 AIIO::workflow
Training（训练）	前向 + 反向传播，反复更新权重。计算量极大、持续时间长，通常多 GPU / 多节点。	AIIO::D1 AIIO::workflow
Inference（推理）	用训练好的固定权重只做前向计算，得到预测。关注延迟、吞吐、成本，长期在线运行。	AIIO::D1 AIIO::workflow
训练和推理的硬件侧重点差异	训练：最大算力、显存容量、节点间高速网络、高速存储。推理：延迟、吞吐/瓦、成本、弹性扩缩。	AIIO::D1 AIIO::workflow
Pretraining（预训练）	在海量通用数据上从零训练基础模型，成本最高（成千上万 GPU、数周到数月）。	AIIO::D1 AIIO::workflow
Fine-tuning（微调）	在预训练模型基础上用领域数据继续训练，使其适配特定任务。	AIIO::D1 AIIO::workflow
Transfer learning（迁移学习）	把在一个任务上学到的知识用于另一个任务，微调是最常见形式。	AIIO::D1 AIIO::workflow
Data preparation（数据准备）	采集、清洗、去重、标注、格式转换。常是最耗时的阶段，可用 RAPIDS 在 GPU 上加速。	AIIO::D1 AIIO::workflow
ETL	Extract-Transform-Load：抽取、转换、加载数据。GPU 加速可用 RAPIDS cuDF / Spark RAPIDS。	AIIO::D1 AIIO::workflow
Data labeling（数据标注）	给样本加上正确答案，供监督学习使用。	AIIO::D1 AIIO::workflow
Model optimization（模型优化）	部署前减小模型、提高速度：量化、剪枝、蒸馏、层融合（TensorRT）。	AIIO::D1 AIIO::workflow
Pruning（剪枝）	移除不重要的权重或结构，减小模型和计算量。	AIIO::D1 AIIO::workflow
Knowledge distillation（知识蒸馏）	用大模型（teacher）的输出训练小模型（student），小模型接近大模型效果。	AIIO::D1 AIIO::workflow
Batch inference vs real-time inference	批量离线推理追求吞吐（如夜间处理数据）；实时在线推理追求低延迟（如聊天、推荐）。	AIIO::D1 AIIO::workflow
Latency（延迟）	单个请求从发出到得到结果的时间。在线服务的关键指标。	AIIO::D1 AIIO::workflow
Throughput（吞吐）	单位时间处理的请求数、样本数或 token 数。	AIIO::D1 AIIO::workflow
Latency vs throughput 的权衡	增大 batch 提高 GPU 利用率和吞吐，但单请求等待和计算时间变长，延迟上升。	AIIO::D1 AIIO::workflow
Checkpoint（检查点）	定期保存模型权重和优化器状态，训练中断后可从最近检查点恢复。	AIIO::D1 AIIO::workflow
为什么大规模训练必须做 checkpoint	上千 GPU 长时间运行，硬件故障几乎必然发生；没有 checkpoint 就要从头训练。	AIIO::D1 AIIO::workflow
Model drift（模型漂移）	上线后真实数据分布变化导致效果下降，需要监控并再训练。	AIIO::D1 AIIO::workflow
MLOps	把 DevOps 实践用于机器学习：数据和模型版本管理、自动训练流水线、部署、监控。	AIIO::D1 AIIO::workflow
Model registry（模型仓库）	存储和版本化训练好的模型及元数据，供部署使用。	AIIO::D1 AIIO::workflow
MLPerf	MLCommons 发布的行业标准 AI 基准测试，分 Training 和 Inference 等类别。	AIIO::D1 AIIO::workflow
Edge inference（边缘推理）	在数据产生地附近（工厂、车、摄像头）推理：低延迟、省带宽、保护隐私。	AIIO::D1 AIIO::workflow
Data center inference vs edge inference	数据中心：大模型、高并发、集中管理；边缘：功耗和体积受限、离线可用、实时性强。	AIIO::D1 AIIO::workflow
CPU vs GPU 设计取向	CPU：少量强核心、大缓存、高频率，延迟优化，擅长串行和复杂分支。GPU：成千上万简单核心，吞吐优化，擅长数据并行。	AIIO::D1 AIIO::gpu-hw
为什么 GPU 适合深度学习	深度学习核心是大规模矩阵乘加，可拆成大量独立运算并行执行；GPU 并行核心多、显存带宽高。	AIIO::D1 AIIO::gpu-hw
SM（Streaming Multiprocessor）	GPU 的基本计算单元，内含 CUDA Core、Tensor Core、寄存器、共享内存/L1。GPU 由几十到上百个 SM 组成。	AIIO::D1 AIIO::gpu-hw
CUDA Core	执行通用标量浮点/整数运算的单元。	AIIO::D1 AIIO::gpu-hw
Tensor Core	专门执行矩阵乘加（MMA）的单元，Volta 首次引入，深度学习加速的主力。	AIIO::D1 AIIO::gpu-hw
RT Core	光线追踪加速单元（Turing 起），用于图形渲染，与 AI 训练无关——常见干扰项。	AIIO::D1 AIIO::gpu-hw
Warp	GPU 调度的基本单位：32 个线程同时执行同一条指令（SIMT）。	AIIO::D1 AIIO::gpu-hw
SIMT	Single Instruction, Multiple Threads：一条指令驱动多个线程处理不同数据。	AIIO::D1 AIIO::gpu-hw
Kernel（CUDA 内核）	在 GPU 上并行执行的函数，以 grid → block → thread 的层次启动。	AIIO::D1 AIIO::gpu-hw
Host vs Device	CUDA 术语：Host = CPU 及其内存；Device = GPU 及其显存。	AIIO::D1 AIIO::gpu-hw
HBM（High Bandwidth Memory）	堆叠在 GPU 封装内的高带宽显存，数据中心 GPU 使用（A100 HBM2e、H100 HBM3、H200/B200 HBM3e）。	AIIO::D1 AIIO::gpu-hw
GDDR 显存	板载显存，带宽低于 HBM、成本低。用于 L4、L40S、RTX 系列等。	AIIO::D1 AIIO::gpu-hw
Memory bandwidth（显存带宽）	每秒能从显存读写的数据量（TB/s）。访存密集型任务（如 LLM decode）的瓶颈。	AIIO::D1 AIIO::gpu-hw
Compute-bound vs memory-bound	计算密集：受 FLOPS 限制（大矩阵乘）；访存密集：受带宽限制（逐元素运算、LLM decode）。	AIIO::D1 AIIO::gpu-hw
Arithmetic intensity（算术强度）	每读写 1 字节数据做多少次运算（FLOPs/Byte）。低 → 访存瓶颈；高 → 计算瓶颈。	AIIO::D1 AIIO::gpu-hw
Roofline model	用算术强度判断性能上限是算力还是带宽的分析模型。	AIIO::D1 AIIO::gpu-hw
FLOPS / TFLOPS / PFLOPS	每秒浮点运算次数。T = 10¹²，P = 10¹⁵。比较时要注意精度和是否含稀疏。	AIIO::D1 AIIO::gpu-hw
L2 cache	所有 SM 共享的片上缓存；MIG 会把 L2 也按实例切分。	AIIO::D1 AIIO::gpu-hw
Shared memory（共享内存）	SM 内、同一 block 线程共享的高速片上存储，程序员可显式管理。	AIIO::D1 AIIO::gpu-hw
Unified Memory（统一内存）	CPU 和 GPU 共用一个地址空间，数据按需自动迁移，简化编程。	AIIO::D1 AIIO::gpu-hw
NVENC / NVDEC	GPU 上的硬件视频编码 / 解码单元。视频分析、转码用，非训练用。	AIIO::D1 AIIO::gpu-hw
Copy engine（拷贝引擎）	GPU 上负责数据搬运（DMA）的单元，可与计算重叠。	AIIO::D1 AIIO::gpu-hw
TDP / TGP	GPU 设计功耗上限。H100 SXM 约 700 W，H100 PCIe 约 350 W，L4 约 72 W。	AIIO::D1 AIIO::gpu-hw
GPU Boost / 降频	GPU 根据功耗、温度余量动态调整频率；过热或触及功耗上限就会降频（throttle）。	AIIO::D1 AIIO::gpu-hw
Compute capability	GPU 架构特性版本号：A100 = 8.0，Ada = 8.9，H100 = 9.0，B200 = 10.0。编译时 sm_XX 要匹配。	AIIO::D1 AIIO::gpu-hw
Structured sparsity（2:4 结构化稀疏）	Ampere 引入：每 4 个权重中 2 个为零时，Tensor Core 可跳过，最高约 2 倍吞吐。	AIIO::D1 AIIO::gpu-hw
DPX instructions	Hopper 引入的动态规划加速指令（基因组比对、路径规划等）。	AIIO::D1 AIIO::gpu-hw
TMA（Tensor Memory Accelerator）	Hopper 引入的硬件单元，异步搬运大块张量数据，减轻 SM 负担。	AIIO::D1 AIIO::gpu-hw
Confidential computing（机密计算）	Hopper 起支持：GPU 内数据在使用中加密隔离，防止宿主机/管理员窥探。	AIIO::D1 AIIO::gpu-hw
RAS engine	Blackwell 引入的可靠性、可用性、可服务性引擎，用于预测性故障检测与诊断。	AIIO::D1 AIIO::gpu-hw
Decompression engine	Blackwell 引入的硬件解压引擎，加速数据分析/数据库查询。	AIIO::D1 AIIO::gpu-hw
架构代际顺序（数据中心）	Pascal → Volta → Turing → Ampere → (Ada Lovelace) → Hopper → Blackwell → Rubin（路线图）。	AIIO::D1 AIIO::gpu-gen
Pascal（P100，2016）	第一代 NVLink，HBM2。	AIIO::D1 AIIO::gpu-gen
Volta（V100，2017）	第一代 Tensor Core；NVLink 2（300 GB/s）。	AIIO::D1 AIIO::gpu-gen
Turing（T4，2018）	INT8/INT4 Tensor Core、RT Core。T4 是经典 70 W 低功耗推理卡（16 GB）。	AIIO::D1 AIIO::gpu-gen
Ampere（A100，2020）	MIG（最多 7 实例）、TF32、2:4 结构化稀疏、第三代 Tensor Core、NVLink 3（600 GB/s）。	AIIO::D1 AIIO::gpu-gen
A100 显存规格	40 GB HBM2（~1.6 TB/s）或 80 GB HBM2e（~2 TB/s）。	AIIO::D1 AIIO::gpu-gen
A30	Ampere 主流计算卡，24 GB HBM2，支持 MIG（最多 4 个实例）。	AIIO::D1 AIIO::gpu-gen
A10 / A10G	Ampere 24 GB GDDR6，推理与图形；A10G 是 AWS g5 实例里的变体。	AIIO::D1 AIIO::gpu-gen
Ada Lovelace（L4 / L40S / RTX 40）	第四代 Tensor Core，支持 FP8；面向推理、图形、视频。本仓库的 RTX 4070 就是 Ada。	AIIO::D1 AIIO::gpu-gen
L4	Ada，24 GB GDDR6，约 72 W，半高单槽。高效推理和视频处理。	AIIO::D1 AIIO::gpu-gen
L40S	Ada，48 GB GDDR6，约 350 W。通用 AI（推理、小规模训练）+ 图形/Omniverse。	AIIO::D1 AIIO::gpu-gen
Hopper（H100，2022）	Transformer Engine（FP8）、第四代 Tensor Core、NVLink 4（900 GB/s）、机密计算、第二代 MIG、DPX。	AIIO::D1 AIIO::gpu-gen
H100 SXM vs H100 PCIe	SXM：80 GB HBM3、~3.35 TB/s、~700 W、NVSwitch 全互联。PCIe：80 GB、更低带宽、~350 W、标准服务器。	AIIO::D1 AIIO::gpu-gen
H100 NVL	面向 LLM 推理的 PCIe 版 H100，成对用 NVLink bridge 连接，显存更大（94 GB/卡）。	AIIO::D1 AIIO::gpu-gen
H200	Hopper 架构，141 GB HBM3e、~4.8 TB/s。相比 H100 主要提升显存容量和带宽，利好 LLM 推理。	AIIO::D1 AIIO::gpu-gen
Grace CPU	NVIDIA 的 Arm 架构数据中心 CPU，LPDDR5X 内存，高能效。	AIIO::D1 AIIO::gpu-gen
GH200 Grace Hopper Superchip	Grace CPU + H100/H200 GPU，通过 NVLink-C2C（900 GB/s）一致性互联，GPU 可直接访问大容量 CPU 内存。	AIIO::D1 AIIO::gpu-gen
Blackwell（B200，2024）	第二代 Transformer Engine（FP4/FP6）、NVLink 5（1.8 TB/s）、双芯片设计、RAS 引擎、解压引擎。	AIIO::D1 AIIO::gpu-gen
B200 显存	约 180–192 GB HBM3e、~8 TB/s；DGX B200 整机 8 卡共 1,440 GB。	AIIO::D1 AIIO::gpu-gen
GB200 Superchip	1 颗 Grace CPU + 2 颗 B200 GPU，NVLink-C2C 连接。	AIIO::D1 AIIO::gpu-gen
GB200 NVL72	液冷机柜：36 Grace + 72 Blackwell GPU，在同一个 NVLink 域内，像一块巨型 GPU，面向万亿参数 LLM。	AIIO::D1 AIIO::gpu-gen
Blackwell Ultra（B300 / GB300）	Blackwell 增强版：更大 HBM3e（约 288 GB）、更强 FP4 推理。	AIIO::D1 AIIO::gpu-gen
Rubin / Vera Rubin	Blackwell 之后的 GPU 架构代号（Vera 为配套 CPU）。路线图级别，了解即可。	AIIO::D1 AIIO::gpu-gen
数据中心卡 vs 消费级卡	数据中心卡：ECC、MIG、NVLink/NVSwitch、长期驱动支持、7×24 设计、DCGM 完整支持。消费卡（GeForce）不面向数据中心部署。	AIIO::D1 AIIO::gpu-gen
RTX PRO / 专业卡	面向工作站和图形 + AI 的专业卡（原 Quadro 系列），支持 vGPU 图形工作站场景。	AIIO::D1 AIIO::gpu-gen
Jetson（Orin / Thor）	嵌入式边缘 AI 模组，用于机器人、无人机、智能摄像头。	AIIO::D1 AIIO::gpu-gen
DGX Spark / DGX Station	桌面级 AI 开发机（Grace Blackwell），本地原型开发后再迁移到数据中心。	AIIO::D1 AIIO::gpu-gen
“首次引入”速记	NVLink=Pascal；Tensor Core=Volta；RT Core=Turing；MIG/TF32/稀疏=Ampere；FP8 Transformer Engine=Hopper；FP4/NVLink5=Blackwell。	AIIO::D1 AIIO::gpu-gen
FP64	双精度。科学计算/HPC 必需，深度学习基本不用。	AIIO::D1 AIIO::precision
FP32	单精度，8 位指数 + 23 位尾数。传统训练基线，混合精度中保存主权重。	AIIO::D1 AIIO::precision
TF32	Ampere 引入的 Tensor Core 计算模式：8 位指数（同 FP32 范围）+ 10 位尾数。FP32 代码无需修改即可加速。	AIIO::D1 AIIO::precision
